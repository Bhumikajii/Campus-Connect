1. STUDENT ROLE:
  User authentication (Sign up, Login, Logout with JWT).
  Browse and search events with filters (category, date, location).
  View detailed event information (description, organizer, date/time, venue).
  Register for events and view a personal list of registrations.
  Bookmark/save favourite events for quick access. 
3. ORGANIZER ROLE:
  All Student capabilities.
  Create, update, and delete events.
  View organiser dashboard with event analytics (total registrations, attendee lists).
5. ADMIN ROLE:
  Moderate platform content (approve/delete any event).
  Manage users (view or ban users if necessary).
